# 基于 SpringBoot + Vue  的点餐配送系统

在线点餐 · 营养分析 · 会员积分 · 多商家入驻 | 面向餐饮外卖、健康饮食与商家运营的一体化配送平台

本项目是一套基于 **Spring Boot + Vue** 的点餐配送系统，采用前后端分离架构，覆盖 **管理员、商家、用户** 三类核心角色。系统围绕"商家入驻 → 菜品展示 → 在线点餐 → 购物车结算 → 营养分析 → 订单配送 → 评价互动 → 积分兑换 → 数据统计"的完整业务闭环设计，打通餐饮外卖全流程，并创新性地融入营养分析功能，助力用户健康饮食。

## 核心特性

- **营养分析系统**：菜品信息包含热量、蛋白质、脂肪等营养成分数据，用户加入购物车或结算时自动累计当日摄入总量，超出推荐摄入量时实时提示，帮助用户科学饮食。
- **多商家入驻体系**：支持商家自主注册、资质审核、店铺信息管理，平台统一管控商家资质与运营规范，形成"平台统筹 + 商家自营"的双层运营模式。
- **会员折扣与积分体系**：用户通过消费获取积分，积分可兑换商品；会员等级享受不同折扣，提升用户粘性与复购率。
- **支付宝沙盒支付 + 邮件通知**：集成支付宝沙盒环境完成支付模拟，支付成功后自动发送邮件通知用户，适合开发测试阶段。
- **多维数据统计**：管理员与商家均可查看销售数据、订单趋势、热门菜品排行等统计报表，支持图表可视化。

## 功能模块概览

## 管理员端

管理员为平台运营中枢，负责全局管控：

### 基础管理

- **注册用户管理**：管理注册用户，包括用户ID、昵称、手机号、注册时间、积分余额、会员等级、账户状态，支持账户冻结/解冻。
- **用户地址管理**：查看用户收货地址列表（省市区、详细地址、联系人、手机号），支持异常地址清理。
- **员工信息管理**：管理平台运营员工，包括员工姓名、工号、角色（内容审核/订单管理/商家管理）、账户状态。
- **个人中心**：显示当天日期时间、日历、登录用户名等基本信息。

### 商家与菜品

- **商家信息管理**：管理全平台商家店铺，包括店铺名称、联系人、联系电话、店铺地址、营业时间、店铺状态，支持店铺冻结/解冻。
- **商家管理模块**：对商家信息进行查询、增加、修改、删除等操作。
- **菜品信息管理**：管理全平台菜品，包括菜品名称、所属商家、菜系分类、价格、库存、规格、营养成分（热量/蛋白质/脂肪）、图片、上下架状态，支持批量操作。

### 订单与评价

- **订单信息**：查看全平台订单，包括订单号、用户、商家、菜品明细、订单金额、支付状态、配送状态、订单状态（待支付/已支付/待接单/配送中/已完成/已取消/已退款），支持订单干预与退款处理。
- **订单评价**：查看用户对订单/菜品的评价，包括评分、评价内容、评价图片，支持屏蔽违规评价。

### 积分与公告

- **积分物品管理**：配置可兑换物品的积分值，包括物品名称、所需积分、库存、兑换规则。
- **公告信息管理**：发布平台公告，包括公告标题、内容、类型（活动通知/系统维护/新商家上线）、发布时间、置顶状态。

### 数据统计

- **销售与统计模块**：综合数据看板，统计系统所有商品销售数量、当天营业额、用户数、商家数、热门菜品排行、积分兑换趋势等，支持按时间段筛选与图表可视化。

### 其他

- **退出登录**：退出到登录页面。

## 商家端

商家通过 Web 后台管理店铺运营：

### 账户与店铺

- **注册/登录模块**：商家进行注册、登录到商家端口。
- **个人中心**：显示当天日期时间、日历、登录用户名等基本信息。
- **员工信息管理**：管理本店员工，包括员工姓名、账号、角色（客服/厨师/配送员）、权限分配。

### 菜品与营养

- **菜系信息管理模块**：管理菜系分类（如川菜/粤菜/湘菜/快餐/饮品），支持查询、添加、修改、删除。
- **菜品管理**：管理本店菜品，包括菜品上架/下架、价格调整、库存管理、规格设置、营养成分录入（热量/蛋白质/脂肪等）、图片上传，支持菜品详情富文本编辑。

### 订单与评价

- **订单管理模块**：查看本店订单，包括待接单、配送中、已完成订单，支持接单、拒单、标记配送中/已完成等操作，查看顾客消费历史记录。
- **菜品评论管理模块**：查看用户对相应菜品的评价，包括评分、评价内容，支持回复评价，维护店铺口碑。

### 会员与积分

- **会员管理模块**：对会员进行增、删、改、查，管理会员等级与折扣规则。
- **店家会员积分调整**：商家可手动调整本店会员用户的积分（如活动赠送、补偿等）。

### 数据统计

- **销售与统计模块**：店铺数据看板，统计本店商品销售数量、当天营业额、热门菜品排行、用户评价统计，支持按时间段筛选。

### 其他

- **退出登录**：退出到登录页面。

## 用户端

用户通过 Web 端进行点餐与互动：

### 账户与个人

- **注册/登录模块**：用户进行注册、登录到用户端口。
- **个人中心**：显示当天日期时间、日历、登录用户名、积分余额、会员等级等基本信息。
- **配送收货地址管理**：管理个人收货地址，支持新增、编辑、删除、设置默认地址，支持省市区三级联动选择。

### 点餐与购物车

- **首页模块**：轮播图推荐热门菜品，支持商户查询、菜系查询、菜品查询，支持关键词搜索与分类筛选。
- **购物车模块**：将心仪菜品加入购物车，支持修改数量、删除菜品、清空购物车，结算时自动计算总价。
- **营养分析模块**：加入购物车或结算时，系统自动累计所选菜品的热量、蛋白质、脂肪等营养成分，与用户当日推荐摄入量对比，超出时实时提示，帮助用户健康饮食。
- **会员折扣模块**：结算时根据用户会员等级自动应用相应折扣，享受会员专属优惠。
- **订单支付**：支持支付宝沙盒支付，支付成功后自动发送邮件通知用户。

### 评价与积分

- **评价模块**：对已消费的菜品进行评价，包括评分、评价内容、图片上传，为其他用户提供参考。
- **积分兑换模块**：通过购买商品获取对应积分，浏览积分商城，使用积分兑换商品。
- **积分物品兑换记录管理**：查看个人积分兑换历史记录，包括兑换物品、消耗积分、兑换时间、配送状态。
